Your Task: "Business Overview Dashboard"
Create a 2-screen Flutter application representing a business dashboard.
What you need to do:
1. Screen 1: The Main Dashboard
○ A welcome header (e.g., "Hello, Admin").
○ 2 to 4 "Summary Cards" at the top (e.g., Total Sales, New Users, Active Projects). Just
use mock numbers.
○ A placeholder for a chart (you can use a simple package like fl_chart or just build a
visual placeholder using colored containers if a chart package is too complex for now).
○ A "Recent Activity" list below the cards.
2. Screen 2: Details/List Page
○ A simple list view showing details (e.g., a list of recent transactions, users, or items).
○ Add a simple navigation mechanism (like a BottomNavigationBar or a Drawer) to move
between Screen 1 and Screen 2.
Technical Expectations:
● Clean, readable code with sensible folder structure (e.g., separating UI, models, and mock
data).
● A responsive layout that looks good on a standard mobile screen size.
● Use of standard Flutter widgets (Rows, Columns, ListViews, Cards).
Submission Guidelines
● Please have a demo ready for the live presentation by the due date.
